## Proyecto principal: Elegant Drops (en producción)

Tienda online real de decants y perfumes, desarrollada, desplegada y operada por mí de principio a fin: **[elegantdrops.cl](https://elegantdrops.cl)**.
Detalle técnico, arquitectura y decisiones de seguridad en **[Elegant-Drops-Showcase](https://github.com/E1egant/Elegant-Drops-Showcase)** (el código fuente es privado).

- Backend en Java 21 + Spring Boot + MySQL, con migraciones Flyway y más de 300 pruebas automatizadas.
- Dos frontends en React + Vite: tienda pública y panel de administración.
- Seguridad: autenticación con roles, verificación en dos pasos para el personal, sesiones revocables, protección CSRF, límites de intentos y precios recalculados en el servidor.
- Despliegue en un VPS Linux con Nginx, Cloudflare, Docker y GitHub Actions.
